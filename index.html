I build with AI, every day.

I'm Isaac. I write the code for AI tools, trading apps and on-chain products, from the contract to the screen.

Most of what I make now has AI in it: a studio that plans and generates film shots, agents that read prediction markets, and a Telegram bot that pays for its own API calls. The rest is the plumbing that makes it real, like Solidity that holds people's money and Python that watches markets while I sleep.

I treat every project like a kata. Build it, use it, fix it, ship it again.
